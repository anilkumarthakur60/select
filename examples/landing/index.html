Keyboard & accessibility

            

              ARIA 1.2 combobox and tree semantics, implemented once in the core so every adapter
              behaves identically. Try any of these on the demos above.
            

          


          

            

              
                Select & combobox
              
              
                

                  ↓ ↑
                  Move the active option
                

                

                  Home End
                  Jump to first / last option
                

                

                  Enter
                  Select the active option
                

                

                  Esc
                  Close the menu, keeping the value
                

                

                  Backspace
                  Remove the last tag when the query is empty
                

                

                  Tab
                  Leave the control and close the menu
                

              
            


            

              
                Tree
              
              
                

                  ↓ ↑
                  Move between visible rows
                

                

                  →
                  Expand a branch, or step into it
                

                

                  ←
                  Collapse a branch, or step out to its parent
                

                

                  Space
                  Toggle the active row
                

                

                  Enter
                  Toggle the active row and keep the menu open
                

                

                  Esc
                  Close the menu
                

              
            

          

        

      


      
      

        

          

            
Why this one

          

          

            

              
One core, real adapters

              

                A pure-TS state machine holds all behaviour. Each adapter is a thin, idiomatic
                binding — v-model in Vue, controlled props in React,
                $bindable
                in Svelte, signals in Solid — not a lowest-common-denominator wrapper.
              

            

            

              
Typed over your data

              

                Full generics over your option type. Accessors, slots and handlers are all typed
                against T, with no any escape hatch in any adapter.
              

            

            

              
Accessible by construction

              

                Combobox and tree roles, focus management across open, close and tag removal, and a
                complete keyboard model — written once, covered by tests, shared by all five
                adapters.
              

            

            

              
Tree mode included

              

                Tri-state parents derived from a flat leaf model, search that matches whole subtrees
                and auto-expands to the hits, and an optional toolbar.
              

            

            

              
Themeable by variable

              

                Design tokens are CSS custom properties under one scope, and every rule sits in
                @layer vselect — so your overrides win without specificity fights.
              

            

            

              
Small and tree-shakeable

              

                Core ~5 kB gz · Vue ~13 kB · React ~8 kB · Svelte/Solid ~6 kB · Web Component ~8 kB
                · CSS ~3 kB. You pay for the adapter you import, nothing else.
