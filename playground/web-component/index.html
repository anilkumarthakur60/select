@anilkumarthakur/select · Web Component

v0.0.1

Custom element <a-select> — works in Angular, Lit, Alpine, Astro, Qwik, plain HTML, and any framework that doesn't get a dedicated package.

Single — primitives

Pass the array of strings via the options property.


        


        

          
Multi — grouped objects

          
Object options with option-value/option-label/option-group attributes are not supported on the WC; instead, set options programmatically and pass already-shaped { value, label } objects.

          
          

        


        

          
Tags — create on the fly

          
Listen for create CustomEvents and push to options.

          
          

        


        

          
Disabled options & sizes

          
size and theme attributes scale the control.

          

            
            
            
          

          

        


        

          
Loading state

          
Toggle the loading attribute to show a spinner.

          
          
        


        

          
Tree — checkbox select

          

            <a-select> is flat-only; the tree-select is rendered with the
            framework-free normalizeTree / walkTree / getLeafValues
            helpers from the core package. Same dataset as the other playgrounds.
          

          

          

        


        

          
Tree — flat (children: [])

          
Same component handles a flat list — renders as a plain checkbox list.
